## Введение

### Что такое Typst?

Typst — это язык разметки для верстки документов. Он разработан для простоты изучения, высокой скорости работы и универсальности. Typst преобразует текстовые файлы с разметкой в PDF-документы.

### Когда использовать Typst?

Typst — отличный выбор для:

- Длинных текстов: эссе, статьи, научные работы, книги, отчеты, домашние задания
- Документов с математическими формулами: работы по математике, физике, инженерии
- Наборов документов с общим стилем: серии книг, корпоративные шаблоны

### Установка и начало работы

Лучший способ начать — зарегистрироваться в [Typst App](https://typst.app) бесплатно. Приложение предоставляет:

- Мгновенный предпросмотр
- Подсветку синтаксиса
- Полезные автодополнения

Альтернативно, можно использовать открытый CLI локально.

## Основы написания документов

### Базовый текст

Просто введите текст в редакторе. Он сразу появится на предпросмотре:

```typst
В этом отчете мы исследуем различные факторы,
влияющие на динамику жидкости в ледниках.
```

### Заголовки

Используйте символ `=` для создания заголовков:

```typst
= Введение

Количество символов `=` определяет уровень вложенности:
= Заголовок первого уровня
== Заголовок второго уровня
=== Заголовок третьего уровня
```

### Выделение текста

- **Жирный текст**: `*жирный*`
- *Курсив*: `_курсив_`
- Комбинация: `*жирный _курсив_*`

### Списки

**Нумерованные списки** используют символ `+`:

```typst
+ Первый пункт
+ Второй пункт
+ Третий пункт
```

**Маркированные списки** используют символ `-`:

```typst
- Элемент один
- Элемент два
- Элемент три
```

**Вложенные списки** создаются отступом:

```typst
+ Климат
  - Температура
  - Осадки
+ Топография
+ Геология
```

### Параграфы

Для создания нового параграфа добавьте пустую строку между текстом.

### Списки терминов

Списки терминов используют синтаксис `/ Термин: описание`:

```typst
/ Ледник: Массив льда, образованный из снега
/ Топография: Описание рельефа местности
/ Геология: Наука о строении Земли
```

### Изображения

Для вставки изображения используйте функцию `image`:

```typst
#image("glacier.jpg")
```

Можно задать размер:

```typst
#image("glacier.jpg", width: 70%)
```

Поддерживаемые форматы: PNG, JPEG, GIF, SVG, PDF, WebP.

### Фигуры с подписями

Используйте функцию `figure` для создания фигуры с подписью:

```typst
#figure(
  image("glacier.jpg", width: 70%),
  caption: [
    _Ледники_ формируют важную часть
    климатической системы Земли.
  ],
)
```

### Ссылки и перекрестные ссылки

**Метки** создаются угловыми скобками:

```typst
#figure(...) <glaciers>
```

**Ссылки** используют символ `@`:

```typst
Ледники, показанные в @glaciers,
перестанут существовать, если мы не примем меры!
```

### Цитаты

Используйте функцию `quote` для цитат:

```typst
#quote[
  Это важная цитата, которая
  будет выделена в документе.
]
```

С атрибуцией:

```typst
#quote(attribution: [Иван Иванов])[
  Это цитата с указанием автора.
]
```

### Сноски

Добавьте сноску с помощью функции `footnote`:

```typst
Это текст со сноской#footnote[Дополнительная информация].
```

### Содержание

Создайте автоматическое содержание:

```typst
#outline()
```

Или содержание для фигур:

```typst
#outline(kind: "figure")
```

### Библиография

Добавьте библиографию с помощью функции `bibliography`:

```typst
#bibliography("works.bib")
```

Цитирование использует тот же синтаксис, что и ссылки:

```typst
Мы следуем моделям таяния ледников,
установленным в @glacier-melt.
```

Typst поддерживает форматы Hayagriva (нативный) и BibLaTeX.

### Математика

**Инлайн-формулы** оборачиваются в `$`:

```typst
Уравнение $Q = rho A v + C$ определяет
скорость ледникового потока.
```

**Блочные формулы** имеют пробелы в начале и конце:

```typst
Скорость потока ледника определяется
следующим уравнением:

$ Q = rho A v + C $
```

**Основные математические конструкции:**

- Подстрочные индексы: `$x_1$`
- Надстрочные индексы: `$x^2$`
- Дроби: `$(a+b)/2$`
- Суммы: `$sum_(i=0)^n x_i$`
- Множественные символы в переменной: `$"time offset"$`

**Функции в математике:**

```typst
$ v := vec(x_1, x_2, x_3) $
$ cal(A) := { x in RR | x > 0 } $
```

**Варианты символов:**

```typst
$ a arrow.squiggly b $
```

## Форматирование

### Set правила

Set правила позволяют применять стили ко всем элементам определенного типа:

```typst
#set text(font: "New Computer Modern", size: 11pt)
#set par(justify: true, leading: 0.52em)
#set heading(numbering: "1.")
```

### Настройка страницы

```typst
#set page(
  paper: "a6",
  margin: (x: 1.8cm, y: 1.5cm),
)
```

Доступные размеры: `"a4"`, `"a5"`, `"a6"`, `"us-letter"`, и другие.

### Выравнивание

```typst
#align(center + bottom)[
  #image("glacier.jpg", width: 70%)
  *Ледники формируют важную часть...*
]
```

### Нумерация заголовков

```typst
#set heading(numbering: "1.")
```

Варианты нумерации:
- `"1."` — арабские цифры
- `"1.a"` — арабские цифры и буквы
- `"I."` — римские цифры

### Show правила

Show правила позволяют переопределить внешний вид элементов:

```typst
#show "ArtosFlow": name => box[
  #box(image("logo.svg", height: 0.7em))
  #name
]

Этот отчет встроен в проект ArtosFlow.
ArtosFlow — проект Института Артос.
```

## Продвинутое оформление

### Заголовки и колонтитулы

```typst
#set page(
  paper: "us-letter",
  header: align(right)[
    Название статьи
  ],
  numbering: "1",
)
```

### Заголовок документа

```typst
#title[
  Название статьи
]
```

Если вы установили `document.title`, можно вызвать `title()` без аргументов:

```typst
#set document(title: [Название статьи])
#title()
```

Настройка заголовка:

```typst
#show title: set text(size: 17pt)
#show title: set align(center)
#show title: set block(below: 1.2em)
```

### Список авторов

```typst
#grid(
  columns: (1fr, 1fr),
  align(center)[
    Иван Иванов \
    Университет \
    #link("mailto:ivan@univ.edu")
  ],
  align(center)[
    Петр Петров \
    Университет \
    #link("mailto:petr@univ.edu")
  ]
)
```

### Аннотация

```typst
#align(center)[
  #set par(justify: false)
  *Аннотация* \
  Текст аннотации...
]
```

### Метаданные документа

```typst
#set document(
  title: [Название статьи],
  author: [Иван Иванов],
  keywords: ("ключевое", "слово"),
)
```

Доступ к метаданным через `context`:

```typst
#set page(
  header: align(
    right + horizon,
    context document.title,
  ),
)
```

### Многоколоночная верстка

```typst
#set page(columns: 2)
```

Элементы, которые должны занимать всю ширину, оборачиваются в `place`:

```typst
#place(
  top + center,
  float: true,
  scope: "parent",
  clearance: 2em,
)[
  #title()
  #grid(...)
  #par(justify: false)[*Аннотация* ...]
]
```

### Стилизация заголовков

**Заголовки первого уровня** (центрированные, малые заглавные):

```typst
#show heading.where(level: 1): set align(center)
#show heading.where(level: 1): set text(size: 13pt, weight: "regular")
#show heading.where(level: 1): smallcaps
```

**Заголовки второго уровня** (run-in, курсив):

```typst
#show heading.where(level: 2): set text(
  size: 11pt,
  weight: "regular",
  style: "italic",
)
#show heading.where(level: 2): it => [
  #it.body + [.]
]
```

## Создание шаблонов

### Переменные

Переменные позволяют переиспользовать значения:

```typst
#let ipa = [taɪpst]

Произношение Typst: #ipa
```

Переменные могут хранить любой тип данных:

```typst
#let blind-text = [_Lorem ipsum_ dolor sit amet]
#let funny-font = "MS Comic Sans"
#let mile = 160934cm
#let double-space = 2em
#let progress = 80%
#let answer = 42
#let truth = false
#let focus = center
```

### Пользовательские функции

```typst
#let amazed(term, color: blue) = {
  text(color, box[✨ #term ✨])
}

Вы #amazed[красивы]!
Я #amazed(color: purple)[изумлен]!
```

### Show-everything правила

Для применения шаблона ко всему документу:

```typst
#let template(doc) = [
  #set text(font: "Inria Serif")
  #show "что-то крутое": [Typst]
  #doc
]

#show: template

Я изучаю что-то крутое сегодня.
```

### Шаблон конференции

```typst
#let conf(
  title,
  authors: (),
  abstract: [],
  doc,
) = {
  set page(
    paper: "us-letter",
    header: align(right + horizon, title),
    columns: 2,
    numbering: "1",
  )
  set par(justify: true)
  set text(font: "Libertinus Serif", size: 11pt)

  // Правила для заголовков
  show heading.where(level: 1): set align(center)
  show heading.where(level: 1): set text(size: 13pt, weight: "regular")
  show heading.where(level: 1): smallcaps

  place(
    top + center,
    float: true,
    scope: "parent",
    clearance: 2em,
    {
      title()

      let count = authors.len()
      let ncols = calc.min(count, 3)
      grid(
        columns: (1fr,) * ncols,
        row-gutter: 24pt,
        ..authors.map(author => [
          #author.name \
          #author.affiliation \
          #link("mailto:" + author.email)
        ]),
      )

      par(justify: false)[
        *Аннотация* \
        #abstract
      ]
    }
  )

  doc
}
```

### Использование шаблона

**В отдельном файле** (`conf.typ`):

```typst
// conf.typ
#let conf(...) = { ... }
```

**В основном файле**:

```typst
#import "conf.typ": conf

#set document(title: [Название статьи])

#show: conf.with(
  authors: (
    (name: "Иван Иванов", affiliation: "Университет", email: "ivan@univ.edu"),
    (name: "Петр Петров", affiliation: "Университет", email: "petr@univ.edu"),
  ),
  abstract: lorem(80),
)

= Введение
...
```

## Справочник по синтаксису

### Режимы Typst

Typst имеет три синтаксических режима:

1. **Markup** (по умолчанию) — обычная разметка
2. **Math** — математические формулы (`$...$`)
3. **Code** — код (`#...`)

### Markup элементы

| Элемент | Пример | Описание |
|---------|--------|----------|
| Параграф | Пустая строка | Разрыв параграфа |
| Жирный | `*жирный*` | Сильное выделение |
| Курсив | `_курсив_` | Выделение |
| Сырой текст | `` `код` `` | Моноширинный текст |
| Ссылка | `https://typst.app/` | Автоматическая ссылка |
| Метка | `<intro>` | Метка для ссылок |
| Ссылка | `@intro` | Перекрестная ссылка |
| Заголовок | `= Заголовок` | Заголовок |
| Маркированный список | `- элемент` | Список |
| Нумерованный список | `+ элемент` | Нумерованный список |
| Список терминов | `/ Термин: описание` | Термины и определения |
| Математика | `$x^2$` | Формула |
| Разрыв строки | `\` | Принудительный разрыв |
| Умные кавычки | `'одинарные'` или `"двойные"` | Автоматические кавычки |

### Математический режим

| Элемент | Пример | Описание |
|---------|--------|----------|
| Инлайн | `$x^2$` | В строке |
| Блок | `$ x^2 $` | Отдельный блок |
| Подстрочный индекс | `$x_1$` | Нижний индекс |
| Надстрочный индекс | `$x^2$` | Верхний индекс |
| Дробь | `$(a+b)/5$` | Дробь |
| Разрыв строки | `$x \ y$` | Разрыв в формуле |
| Точка выравнивания | `$x &= 2 \ &= 3$` | Выравнивание |
| Переменная | `$#x$`, `$pi$` | Доступ к переменным |
| Доступ к полю | `$arrow.r.long$` | Модификаторы символов |
| Неявное умножение | `$x y$` | Умножение |
| Текст в формуле | `$a "естественно"$` | Текстовая строка |
| Вызов функции | `$floor(x)$` | Математические функции |

### Режим кода

| Элемент | Пример | Описание |
|---------|--------|----------|
| None | `none` | Отсутствие значения |
| Boolean | `false`, `true` | Логические значения |
| Целое число | `10`, `0xff` | Целые числа |
| Число с плавающей точкой | `3.14`, `1e5` | Вещественные числа |
| Длина | `2pt`, `3mm`, `1em` | Размеры |
| Угол | `90deg`, `1rad` | Углы |
| Дробь | `2fr` | Доли |
| Процент | `50%` | Проценты |
| Строка | `"hello"` | Строки |
| Массив | `(1, 2, 3)` | Массивы |
| Словарь | `(a: "hi", b: 2)` | Словари |
| Унарный оператор | `-x` | Один операнд |
| Бинарный оператор | `x + y` | Два операнда |
| Присваивание | `x = 1` | Присваивание |
| Доступ к полю | `x.y` | Поля |
| Вызов метода | `x.flatten()` | Методы |
| Вызов функции | `min(x, y)` | Функции |
| Распаковка аргументов | `min(..nums)` | Spread оператор |
| Безымянная функция | `(x, y) => x + y` | Лямбда |
| Привязка | `let x = 1` | Переменные |
| Именованная функция | `let f(x) = 2 * x` | Функции |
| Set правило | `set text(14pt)` | Стилизация |
| Show правило | `show heading: set block(..)` | Показ правил |
| Контекст | `context text.lang` | Контекст |
| Условие | `if x == 1 {..} else {..}` | Условия |
| Цикл for | `for x in (1, 2, 3) {..}` | Циклы |
| Цикл while | `while x < 10 {..}` | Циклы |
| Комментарий | `/* блок */`, `// строка` | Комментарии |

### Комментарии

```typst
// Однострочный комментарий

/* Многострочный
   комментарий */
```

### Escape-последовательности

```typst
Я получил мороженое за \$1.50! \u{1f600}
```

### Идентификаторы

Имена переменных и функций могут содержать буквы, цифры, дефисы (`-`) и подчеркивания (`_`). Должны начинаться с буквы или подчеркивания.

Рекомендуется использовать kebab-case для многословных идентификаторов:

```typst
#let kebab-case = [Использование дефиса]
#let _schön = "😊"
#let π = calc.pi
```

### Пути к файлам

**Относительные пути** (от текущего файла):

```typst
#image("images/logo.png")
```

**Абсолютные пути** (от корня проекта, начинаются с `/`):

```typst
#image("/assets/logo.png")
```

## Скриптинг

### Выражения

Встраивание кода в разметку:

```typst
#emph[Привет] \
#emoji.face \
#"hello".len()
```

### Блоки

**Блок кода** (множественные выражения):

```typst
#{
  let x = 1
  let y = 2
  x + y
}
```

**Блок содержимого** (разметка как значение):

```typst
#let content = [*Привет* мир!]
#content
```

### Привязки и деструктуризация

```typst
#let name = "Typst"
Это документация #name.

#let (x, y) = (1, 2)
Координаты: #x, #y.

#let (a, .., b) = (1, 2, 3, 4)
Первый элемент: #a.
Последний элемент: #b.
```

### Условия

```typst
#if 1 < 2 [
  Это показывается
] else [
  Это не показывается
]
```

### Циклы

**Цикл for:**

```typst
#for c in "ABC" [
  #c — это буква.
]

#for (key, value) in (a: 1, b: 2) [
  #key: #value
]
```

**Цикл while:**

```typst
#let n = 2
#while n < 10 {
  n = (n * 2) - 1
  (n,)
}
```

**Управление циклом:**

```typst
#for letter in "abc nope" {
  if letter == " " {
    break
  }
  letter
}
```

### Поля и методы

```typst
#let it = [= Заголовок]
#it.body \
#it.depth

#"abc".len() \
#str.len("abc")
```

### Модули

**Включение:**

```typst
#include "bar.typ"
```

**Импорт:**

```typst
#import "bar.typ"
#import "bar.typ" as baz
#import "bar.typ": a, b
#import "bar.typ": a as one, b as two
```

**Пакеты:**

```typst
#import "@preview/example:0.1.0": add
#add(2, 7)
```

### Операторы

| Оператор | Эффект | Аритет | Приоритет |
|----------|--------|--------|-----------|
| `-` | Отрицание | Унарный | 7 |
| `*` | Умножение | Бинарный | 6 |
| `/` | Деление | Бинарный | 6 |
| `+` | Сложение | Бинарный | 5 |
| `-` | Вычитание | Бинарный | 5 |
| `==` | Равенство | Бинарный | 4 |
| `!=` | Неравенство | Бинарный | 4 |
| `<`, `<=`, `>`, `>=` | Сравнение | Бинарный | 4 |
| `in`, `not in` | Принадлежность | Бинарный | 4 |
| `not` | Логическое "не" | Унарный | 3 |
| `and` | Логическое "и" | Бинарный | 3 |
| `or` | Логическое "или" | Бинарный | 2 |
| `=`, `+=`, `-=`, `*=`, `/=` | Присваивание | Бинарный | 1 |

## Контекст

### Стилевой контекст

Доступ к значениям set правил:

```typst
#set text(lang: "de")
#context text.lang
```

### Контекст местоположения

Получение значений счетчиков:

```typst
#set heading(numbering: "1.")
= Введение
#lorem(5)
#context counter(heading).get()
```

Использование `here()`:

```typst
= Введение <intro>
#lorem(5)
= Фон <back>
#lorem(5)

#context [
  #counter(heading).get() \
  #counter(heading).at(here()) \
  #counter(heading).at(<intro>)
]
```

Получение физической позиции:

```typst
= Введение <intro>
#lorem(5)
#pagebreak()
= Фон <back>
#lorem(5)

Фон находится на: \
#context locate(<back>).position()
```

### Вложенные контексты

Контекст доступен из вложенных вызовов функций:

```typst
#let foo() = 1em.to-absolute()
#context {
  foo() == text.size
}
```

## Стилизация

### Set правила

Настройка внешнего вида элементов:

```typst
#set heading(numbering: "I.")
#set text(font: "New Computer Modern")

= Введение
С помощью set правил можно стилизовать документ.
```

**Область действия:**

```typst
Этот список затронут: #[
  #set list(marker: [--])
  - Тире
]

Этот нет:
- Маркер
```

**Условные set правила:**

```typst
#let task(body, critical: false) = {
  set text(red) if critical
  [- #body]
}

#task(critical: true)[Еда сегодня?]
#task(critical: false)[Дедлайн работы]
```

### Show правила

**Show-set правила:**

```typst
#show heading: set text(navy)

= Это темно-синий
А это остается черным.
```

**Трансформационные show правила:**

```typst
#set heading(numbering: "(I)")
#show heading: set align(center)
#show heading: set text(font: "Inria Serif")
#show heading: it => block[
  \~
  #emph(it.body)
  #counter(heading).display(it.numbering)
  \~
]

= Дракон
С базовым здоровьем 15, дракон — самое мощное существо.
```

**Различные селекторы:**

```typst
// Все
#show: rest => ..

// Текст
#show "Текст": ..

// Регулярное выражение
#show regex("\w+"): ..

// Функция с полями
#show heading.where(level: 1): ..

// Метка
#show <intro>: ..
```

## Полезные функции

### Работа с текстом

- `emph(content)` — курсив
- `strong(content)` — жирный
- `smallcaps(content)` — малые заглавные
- `underline(content)` — подчеркивание
- `strike(content)` — зачеркивание
- `highlight(content, color)` — выделение цветом
- `raw(text, lang)` — сырой текст с подсветкой синтаксиса
- `quote(content, attribution)` — цитата
- `footnote(content)` — сноска
- `outline(kind)` — содержание (table of contents)

### Работа с изображениями

- `image(path, width, height)` — вставка изображения
- `figure(content, caption)` — фигура с подписью

### Работа с таблицами

```typst
#table(
  columns: 2,
  [Заголовок 1], [Заголовок 2],
  [Ячейка 1], [Ячейка 2],
)
```

### Работа с математикой

- `frac(numerator, denominator)` — дробь
- `sum_(from)^(to) expression` — сумма
- `integral_(from)^(to) expression` — интеграл
- `vec(x, y, z)` — вектор-столбец
- `mat(1, 2; 3, 4)` — матрица

### Работа с макетом

- `align(alignment, content)` — выравнивание
- `grid(columns, content)` — сетка
- `stack(direction, content)` — стек
- `place(alignment, content)` — размещение
- `columns(count, content)` — колонки
- `pagebreak()` — разрыв страницы
